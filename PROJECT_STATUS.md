# Портфолио Мустафы — статус проекта

Последняя проверка: **19 сентября 2026**.

## Состояние

Сайт завершён как статическое портфолио с интерактивными разделами. Изменения сохранены локально поверх `2312653` в ветке `main`. Коммит, push и публикация в этой задаче не выполнялись. Папка `задача/` и исходные фотографии/скриншоты сохранены.

Готовая сборка: `http://127.0.0.1:4173/`. Сервер разработки: `http://127.0.0.1:5173/`.

## Реализовано

- Главная: первый экран, пять проектов, другие работы, полноценные услуги, четыре этапа работы, «Обо мне», шесть вопросов FAQ, контактный бриф и подвал.
- Пять подробных кейсов: `/projects/fuellead/`, `/projects/chef-choice/`, `/projects/finance/`, `/projects/leppa-wenston/`, `/projects/olympion/`. Задача, роль, ключевые решения, экраны, результат, стек и переходы к другим работам.
- Маршрутизация React Router, переходы из кейсов к разделам главной, прокрутка и перевод фокуса после навигации, страница 404.
- Framer Motion: последовательное появление первого экрана, появление блоков при прокрутке, мобильное меню, раскрытие FAQ и предпросмотр брифа, индикатор прокрутки. Учтён `prefers-reduced-motion`.
- Мобильное меню на нативном dialog: Escape, блокировка прокрутки фона, цикл Tab/Shift+Tab и возврат фокуса.
- Контактный бриф с проверкой обязательного описания, предпросмотром, копированием и ссылкой на личный чат Telegram с подготовленным текстом. Форма честно объясняет: посетитель сам отправляет сообщение в Telegram. Серверной отправки и хранения заявок нет.
- Полный HTML главной, пяти кейсов и 404 генерируется при сборке. React гидратирует готовую разметку. Основное содержимое видно без ожидания JavaScript; все ответы FAQ присутствуют в HTML.
- Для каждого маршрута: title, description, canonical, Open Graph, Twitter Card и JSON-LD. Добавлены sitemap, robots, favicon и превью 1200×630.
- Vercel настроен на статическую папку dist без wildcard rewrite; неизвестный адрес получает настоящий 404. Локальный preview повторяет это поведение.
- Неподтверждённые показатели опыта и выручки заменены описанием функций и вычисляемыми числами: 5 кейсов, 25 экранов и 3 дополнительные работы. Цены и сроки обсуждаются по задаче; отзывы не выдуманы.

## Проверено

- `npm run typecheck`, `npm run build`, `npm run check:site`, `git diff --check` проходят.
- Статические проверки: уникальные title, description, canonical и h1; отсутствие повторяющихся id; существование изображений, размеров и alt; все внутренние маршруты и якоря; JSON-LD и noindex для 404.
- HTTP: главная и пять кейсов — 200; отсутствующий адрес — 404; каноническая косая черта — 308 с сохранением query; статические ресурсы и шрифты доступны.
- Chrome: главная на 320, 390, 768, 1024, 1056, 1057 и 1440 CSS px без горизонтального переполнения. Исправлен перенос заголовка первого экрана при 768 и 1057 px.
- Все пять кейсов проверены на 320 и 1440 px: заголовки не обрезаются, горизонтального переполнения нет, прямое открытие и обновление работают.
- Все 25 слайдов перелистаны на 320 и 1440 px: высота каждой галереи постоянна, изображения целиком через contain, циклическое переключение работает. Проверено управление стрелками клавиатуры.
- Мобильное меню: открытие, Escape, Tab/Shift+Tab, возврат фокуса, переход к разделу. FAQ раскрывается, aria-controls всегда указывает на существующий ответ.
- Бриф: пустое/пробельное описание отклоняется, корректный ввод создаёт черновик, копирование подтверждено, изменение ввода убирает прежний черновик. Сообщения в Telegram при тестировании не отправлялись.
- Метаданные при клиентском переходе обновляются без дублирования; гидратация главной и кейсов прошла без ошибок. В проверке финальной сборки в Chrome ошибок и предупреждений нет.
- Семь внешних адресов проектов/GitHub ответили HTTP 200. Это проверка доступности ссылок, а не аудит работы этих приложений.

## Важные решения

- Карусели сохраняют постоянное соотношение сторон каждого проекта и резервирование высоты подписей. `activeSlideRef` и `programmaticTargetRef` сохранены.
- В FuelLead указано использование AI-инструментов для серверной части и почтовых интеграций. Демонстрационные данные на скриншотах подписаны.
- Собственный домен, сторонняя аналитика и серверный приём заявок не подключены. Для текущего контактного сценария они не нужны; никаких внешних аккаунтов и секретов не добавлено.
- Реальные телефоны, Safari/Firefox и опубликованная версия в рамках этой доработки не проверялись. Reduced motion реализован в настройке MotionConfig, hooks и CSS; отдельная браузерная эмуляция этой настройки не проводилась.

Инструкции по запуску, структуре и публикации находятся в README.md.
