# Портфолио Мустафы

React 19, TypeScript, Vite и Framer Motion. Главная страница, пять подробных кейсов и страница 404. Скриншоты проектов хранятся в `public/projects/`.

## Локальный запуск

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Проверка сборки, статических страниц и предпросмотр:

```sh
npm run build
npm run check:site
npm run preview
```

Предпросмотр доступен на `http://127.0.0.1:4173`. Другой порт: `npm run preview -- 4174`. Он обслуживает собранные HTML-файлы и возвращает настоящий HTTP 404 для неизвестных адресов.

## Контент и устройство

- `src/data/projects.ts` — проекты, ссылки и размеры скриншотов. У каждого проекта постоянная пропорция карусели: смена слайда не меняет высоту страницы.
- `src/data/cases.ts` — задачи, роль, решения и результаты пяти кейсов.
- `src/components/SiteSections.tsx` — услуги, процесс, информация о разработчике, FAQ и контактный бриф.
- `src/data/site.ts` — адрес сайта, контакты и общие SEO-данные.
- `src/components/Seo.tsx` — метаданные страницы и JSON-LD.
- `scripts/prerender.mjs` — создаёт HTML главной, кейсов и 404 после сборки Vite. Контент доступен до загрузки JavaScript; клиент использует гидратацию.
- `scripts/check-site.mjs` — проверяет метаданные, локальные ссылки, якоря, изображения и страницу 404 в собранном сайте.

Анимации учитывают системный `prefers-reduced-motion`. Для мобильного меню используется нативный диалог с управлением фокусом и закрытием по Escape.

## Контактный бриф

Форма помогает составить сообщение. Посетитель проверяет текст, копирует его или открывает личный чат `@mustafa_proger` с подготовленным черновиком. Отправку подтверждает сам посетитель в Telegram. Данные формы не сохраняются на сервере. Сторонняя аналитика не подключена.

## Публикация

`vercel.json` настроен на статическую папку `dist`: команда `npm run build` создаёт готовые страницы для каждого маршрута. Файл `404.html` обслуживается как страница ошибки. Wildcard-перенаправление всех адресов на главную не требуется.

Текущий базовый адрес: `https://mustafa-proger.vercel.app`. При смене домена обновите `src/data/site.ts`, `public/sitemap.xml` и адрес sitemap в `public/robots.txt`, затем пересоберите проект. Для нового кейса добавьте данные в `projects.ts`, `cases.ts` и маршрут в sitemap.
